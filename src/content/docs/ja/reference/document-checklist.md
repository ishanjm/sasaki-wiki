日本の在留資格認定証明書（COE）審査を円滑に進めるためには、正確かつ不備のない書類準備が不可欠です。スリランカ発行の公的書類は、公認翻訳者による英訳または和訳の添付が必須となります。

---

## 1. 申請者本人の書類

| 書類名 | 備考 | 留学 | 特定技能 / 実習 |
| :--- | :--- | :---: | :---: |
| **旅券（パスポート）** | 渡航予定日から1年以上有効な原本および身分事項ページのカラーコピー | 必須 | 必須 |
| **証明写真** | 縦4.0cm × 横3.0cm、白無地背景、3か月以内撮影 | 6枚 | 6枚 |
| **出生証明書** | 発行から6か月以内の原本および公認英訳・認証 | 必須 | 必須 |
| **国民身分証明書（NIC）** | 両面カラーコピーおよび公認英訳 | 必須 | 必須 |
| **無犯罪証明書（Police Clearance）** | スリランカ警察本部発行（有効期間6か月） | 推奨 | 必須 |
| **健康診断書** | 指定クリニックでの胸部レントゲン、血液検査、ECG等の検査結果 | 必須 | 必須 |

## 3. 経費支弁関係書類（主に留学ビザ）

| 書類名 | 内容 | 提出目的 |
| :--- | :--- | :--- |
| **経費支弁書** | 学費・生活費の全額支弁を誓約する支弁者自署の所定様式 | 支弁意思の証明 |
| **預金残高証明書** | 商業銀行発行の原本（**日本円換算250万〜300万円相当**） | 即時支払能力の証明 |
| **預金通帳・取引明細書（1〜3年分）** | 預金の形成過程と定期的な資金移動を示す明細 | 資金形成の正当性確認 |
| **収入証明書・給与明細書** | 過去12か月の給料明細および所属機関の在職証明書 | 継続的収入能力の証明 |
| **個人事業登記簿（BR）** | 支弁者が事業主の場合の登記謄本 | 事業実態の確認 |
| **納税証明書（過去3年分）** | スリランカ国税局（IRD）発行の納税記録 | 所得申告の真正性確認 |
| **親族関係証明書類** | 申請者と支弁者の続柄を証明する出生証明書 | 親族関係の客観的証明 |

## 4. 日本側受入機関から発行される書類

- **在留資格認定証明書（COE）原本**: 出入国在留管理局より交付。
- **入学許可書**（留学）または **雇用契約書・労働条件通知書**（特定技能・就労）。
- **受入機関概要書**: 企業謄本、学校案内パンフレット。
- **支援計画書**: 登録支援機関による1号特定技能支援計画。

---

## 5. スリランカ海外雇用局（SLBFE）要件

海外就労ビザ（特定技能、技能実習）の場合：
1. **SLBFE就労登録および生体認証登録**。
2. **SLBFE海外就労者保険の加入**。
3. **二国間雇用契約書の公的認証**。
