**特定技能制度（Specified Skilled Worker - SSW）**は、日本国内で深刻化する労働力不足に対応するため、一定の専門性・技能と日本語能力を有する外国人材の就労を促進する目的で創設された在留資格です。

**ササキ海外雇用エージェンシー（Sasaki Foreign Employment Agency）**では、スリランカ現地の優秀な若手人材を対象に、JFT-Basic/JLPT指導、各分野の技能評価試験対策、日本の受入企業様との面接マッチング、そして在留資格認定証明書（COE）申請まで包括的に支援しています。

:::tip[適正かつ迅速な人材供給]
特定技能1号制度を通じ、入国後即戦力として活躍できる教育水準の高いスリランカ人財を迅速に受入企業様へマッチングいたします。
:::

## 特定技能1号と2号の比較

| 項目 | 特定技能1号 | 特定技能2号 |
| :--- | :--- | :--- |
| **技能水準** | 相当程度の知識または経験を必要とする技能 | 熟練した技能（現場リーダー・監督者レベル） |
| **在留期間** | 通算**上限5年**（1年、6か月、4か月ごとの更新） | **上限なし**（要件を満たせば永住申請も可能） |
| **日本語能力** | JFT-Basic（A2水準）または JLPT N4以上 | 業務上必要な高度な日本語運用能力 |
| **技能試験** | 分野別技能測定試験 | 第2号技能測定試験または熟練評価試験 |
| **家族帯同** | 原則不可 | **可能**（配偶者および子） |
| **支援体制** | 登録支援機関による生活・就労支援計画の実施義務 | 受入企業様による直接管理（支援義務なし） |

## 主な対象産業分野

1. **介護**  
   *要件*: 国際交流基金日本語基礎テスト（またはJLPT N4以上）に加え、「介護日本語評価試験」および「介護技能評価試験」の双方の合格が必要。
2. **外食業**  
   飲食店での接客、調理、衛生管理、店舗運営サポート。
3. **飲食料品製造業**  
   食品加工工場、品質管理、衛生包装、製造ラインオペレーション。
4. **農業**  
   施設園芸、露地栽培、収穫・選別、畜産（養豚・酪農・養鶏）。
5. **建設業**  
   型枠、鉄筋、とび、内装仕上げ、土工、建設機械施工。
6. **素形材・産業機械・電気電子情報関連製造業**  
   鋳造、機械加工、金属プレス、溶接、電子機器組立。
7. **宿泊業**  
   フロント、案内、予約受付、客室サービス。
8. **自動車整備業**  
   日常点検、車検整備、分解点検、電子制御診断。
9. **ビルクリーニング**  
   商業施設・医療機関の清掃機材を用いた衛生管理。

## 採用候補者の要件

- **年齢**: 満18歳以上。
- **言語要件**:
  - **JFT-Basic（国際交流基金日本語基礎テスト）**（200点以上/250点中）、または
  - **JLPT N4**以上の合格証。
- **技能要件**: 各産業分野が指定するPrometric技能測定試験の合格。
- **技能実習修了者の免除措置**: 日本で同職種の技能実習2号を良好に修了した候補者は、**技能試験および日本語試験が免除**され、スムーズに特定技能1号へ移行できます。

## 労働法令の遵守と処遇基準

- **日本人と同等以上の報酬**: 同一業務に従事する日本人従業員と同等以上の給与水準が法令で義務付けられています。
- **社会保険完備**: 健康保険、厚生年金、雇用保険、労災保険の適用。
- **転職の自由**: 同一分野内での転職が法的に認められています。
