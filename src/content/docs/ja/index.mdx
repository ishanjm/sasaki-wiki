## 採用・渡日のプロセス

候補者の募集から日本での就業までのステップ：

<Steps>
1. **登録と適性評価**
   学歴・職歴の確認、面接、健康状態のスクリーニング。

2. **日本語・技能教育**
   自社アカデミーにて日本語学習（JLPT / JFT-Basic）および技能評価試験の対策。

3. **企業面接と雇用契約**
   受入企業様との面接（オンラインまたは現地対面）を実施し、雇用契約を締結。

4. **COE申請とビザ発給**
   出入国在留管理庁への在留資格認定証明書（COE）交付申請およびビザ発給手続き。

5. **出国前講習と渡日**
   渡航前オリエンテーション、諸手続きの完了、日本への出国。
</Steps>

## 主な対応職種

- **介護** — 専門用語や尊厳に配慮した介助技術を習得した人材
- **外食業** — 接客・衛生管理を徹底したスタッフ
- **飲食料品製造業** — 工場での製造・加工・品質管理
- **農業** — 施設園芸、畑作、畜産管理
- **建設業** — とび、型枠、鉄筋、内装仕上げ
- **素形材・産業機械・電気電子情報関連製造業** — 機械加工、溶接、組立
